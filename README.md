# Calculator – GUI Based Application

This is a GUI-based Calculator project that I developed using Python and Tkinter. It is designed to perform basic mathematical calculations through a simple graphical interface.

I also added some extra features like square root, square, percentage, and calculation history to make it more useful.

# Features

- Addition, Subtraction, Multiplication and Division
- Percentage calculation
- Square root
- Square of a number
- Brackets support
- Decimal calculations
- Backspace and Clear options
- Calculation history
- Keyboard input support
- Error handling for invalid calculations and division by zero

# Technologies Used

- Python
- Tkinter
- AST Module
- Operator Module
- Math Module

# What I Learned

- Creating GUI-based applications using Tkinter.
- Working with buttons and input fields.
- Using Python functions and modules.
- Handling mathematical expressions safely using AST.
- Implementing keyboard input and error handling.
- Displaying calculation history.
